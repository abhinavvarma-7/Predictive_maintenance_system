# Predictive Maintenance System

## Project Overview
This Predictive Maintenance System is designed to detect and predict the failure of machinery to ensure timely maintenance, reduce downtime, and increase efficiency.

## Features
- **Real-time Monitoring**: Track the performance of machinery 24/7.
- **Predictive Analytics**: Use machine learning models to forecast potential failures based on historical data.
- **User-friendly Dashboard**: Provides insights and analytics in an easy-to-read format.
- **Alerts and Notifications**: Get notified for anomalies or predicted failures to take action immediately.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/abhinavvarma-7/Predictive_maintenance_system.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Predictive_maintenance_system
   ```
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
1. Start the application:
   ```bash
   python app.py
   ```
2. Access the dashboard by navigating to `http://localhost:5000` in your web browser.
